# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Приложение

- Обновления: раз в сутки (по напоминанию ядра и при открытии) Жор спрашивает у GitHub последнюю версию и,
  если она новее, присылает уведомление; на сводке — плашка, в настройках — блок «Обновления» с «Что нового».
  Ставит только по кнопке «Обновить»: скачивает APK, сверяет SHA-256 из `SHA256SUMS`, пакет, версию и сертификат
  подписи с установленным и ставит через ядро (root), без системного окна установки. Проверку можно выключить.
- **Приложению теперь нужно разрешение на интернет** — только для этого. Записи и отчёты никуда не уходят, вся
  работа с сетью — в `Updater.kt`.

### Ядро `zhord`

- Раз в сутки будит приложение проверить обновление (`config.update_check`); команда `install_apk` ставит
  скачанный приложением APK через `pm install` и открывает новую версию.

### Выпуски

- В выпуске есть `zhor.apk` — копия APK без версии в имени: `…/releases/latest/download/zhor.apk` всегда отдаёт
  последнюю версию.

## [0.6.0] — 2026-11-23

Сторож: уведомление в момент, когда что-то жрёт батарею, ограничение фона прямо из карточки приложения,
сравнение «до/после» — и всё, что Жор меняет в системе, можно вернуть.

### Ядро `zhord`

- Сторож: раз в 5 минут на обычном шаге (телефон не будит) проверяет текущий покой — экран выключен, без
  зарядки — по пяти правилам: телефон не спит, батарея тает, частые пробуждения, приложение в фоне, греется.
  Тревога — раз за период на правило и виновника, в `alerts.jsonl` и рассылкой в приложение. Пороги и «не
  напоминать» — в настройках ядра. Команды `alerts`, `alert_test`, `mute`; CLI `zhord alerts`, `alert-test`,
  `watch-check` (прогон правил по записям).
- Действия с приложением: ограничить или разрешить работу в фоне (`RUN_ANY_IN_BACKGROUND`), остановить;
  журнал `actions.jsonl`. Команды `app_state`, `act`, `actions`.
- Сравнение «до/после» по покою, приведённому к часу: два последних периода покоя, до и после действия или
  два любых отрезка; с `uid` — ещё процессор, запуски, будильники, wakelock и задания приложения. Команда
  `compare`, CLI `zhord compare`.
- «Вернуть всё»: команды `restricted` и `revert_all`, CLI `zhord restricted` / `revert-all` (работают и без
  демона) — каждому, кого ограничил Жор, возвращается режим до него; то, что поменяли с тех пор сами, не трогается.
  Журнал действий больше не стирается очисткой данных.
- Приложение удалили: через 10 минут ядро возвращает ограничения, выключает подробную историю Android, убирает
  свой автозапуск и останавливается; записи остаются.

### Приложение

- Уведомления сторожа с кнопкой «Не напоминать»; нажатие открывает отчёт за тот период и приложение.
- Экран «Сторож»: включение, разрешение на уведомления, проверочное уведомление, пороги правил, список тревог,
  приглушённое, журнал действий.
- В карточке приложения — «Работа в фоне»: состояние, «Ограничить фон» / «Разрешить фон», «Остановить» и «До/после».
- Экран сравнения: итог, покой телефона, приложение, кто тратил процессор в обоих отрезках.
- На сводке — «Сторож заметил», если за сутки были тревоги.
- «Что Жор меняет в системе» на экране «Сторож»: кто ограничен Жором, «Вернуть всё», что будет при удалении.
- Окно «Сторожу нужны уведомления» при запуске, если сторож включён, а уведомления запрещены; после двух отказов
  в системном запросе — сразу настройки уведомлений.

### Исправлено

- Зарядка больше не портит отчёт: экран вкл./выкл. и глубокий сон считаются только без зарядки (экран вкл. +
  выкл. + зарядка = период), поэтому на зарядке нет ложного «телефон почти не спит».
- Доли приложений и цена самого Жора считаются от большего из факта по счётчику и суммы приложений — на зарядке
  было «Android OS 5030 %».
- Загрузка GPU: `gpubusy` у kgsl — окно около секунды, а не накопительный счётчик (было «GPU занят 550 %»);
  старые записи обрезаются до 100 %.

## [0.5.0] — 2026-11-23

Первый открытый выпуск.

### Ядро `zhord`

- Энергия каждого потока: время на каждой частоте (`time_in_state`) × ток ядра из профиля мощности,
  сверка с кулоновским счётчиком батареи.
- Сон: доля глубокого сна, сорванные засыпания, источники и причины пробуждений, нативные wakelock служб
  и HAL с PID.
- Статистика Android: модель по приложениям (`--usage`), сводка через `--proto`, история событий
  batterystats с точностью до миллисекунды.
- «За кого работает system»: какое приложение сколько процессорного времени `system_server` потратило
  и каким вызовом (`binder_calls_stats`, `looper_stats`).
- Рендеры WebView и песочницы относятся к приложению-хозяину.
- Выводы с порогами «хорошо / так себе / плохо» и подсказками; выгрузка JSON, текста и сырых записей.
- Цена самого ядра — около 2 мА при включённом экране; сну не мешает.

### Приложение

- Экраны: сводка, лента с разбором любой минуты, «Кто жрёт», карточка приложения с лентой по времени,
  «Почему столько», «Сон», «За кого работает system», «Сейчас».
- Настройки: частота шага, срок хранения, автозапуск, подробная история Android; размер данных и выгрузка.
